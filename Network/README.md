라우팅과 VLAN 문서에는 토폴로지, 설정, 라우팅 테이블 또는 Ping 캡처가 포함된 항목이 있습니다. 문서마다 실습 범위는 다릅니다.

**작성 중:** `6. switching`의 Inter-VLAN Routing, STP, VTP 파일은 현재 내용이 비어 있습니다. EtherChannel, ACL, DHCP 등의 항목은 이 저장소에 아직 없습니다.
